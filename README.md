# grundlagen_informatik_1-uebung6
tasks for learning the language "Python"

Aufgabe 1

Schreiben Sie eine Funktion, die eine Tabelle des 
Einmaleins auf dem Bildschirm ausgibt!
Die Zeilen- und Spalten sollen dabei mit ihrer Nummer 
beschriftet werden und in den jeweiligen Zellen der 
Tabelle soll das Ergebnis der Multiplikation der 
jeweiligen Zeilen mit der Spaltennummer eingetragen 
werden.
Der Funktion ist als Parameter die Zahl zu übergeben, 
bis zu der das “Einmaleins” berechnet werden soll. Sie 
können hierbei davon ausgehen, dass keine Werte 
größer als 25 eingegeben werden.

Aufgabe 2

Schreiben Sie je eine Funktion, die ein Dreieck wie angegeben auf den Bildschirm zeichnet! 
Funktionsargument sei jeweils die Höhe des Dreiecks (= Anzahl der Zeilen).
